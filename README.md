# Webtech Wheelhouse — Workshop Management System

Wheelhouse is a Ruby on Rails application for managing bike repairs, customers, mechanics, and services.

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd webtech-wheelhouse
Install dependencies and setup database:

Bash
bin/setup
(Or alternatively: bundle install followed by bin/rails db:prepare or bin/rails db:reset)

Start the development server:

Bash
bin/dev
# or
bin/rails server
Access the application:
Open http://localhost:3000 in your browser.
